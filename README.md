# triton-cloud-automation
Sistema de orquestación de infraestructura en la nube y automatización DevOps desarrollado en **Python** utilizando el **SDK Boto3** de AWS y emulación local desacoplada mediante **LocalStack** y **Docker**.

Este repositorio evoluciona la arquitectura del **Proyecto Tritón** https://github.com/FernandaPuca1811/triton_monitor.git incorporando patrones de **Infraestructura como Código (IaC)**, aprovisionamiento idempotente de recursos de cómputo/almacenamiento y orquestación programática de topologías de red privada (VPCs, Subnets, Internet Gateways y Security Groups).
