# triton-cloud-automation
Sistema de orquestación de infraestructura en la nube y automatización DevOps desarrollado en **Python** utilizando el **SDK Boto3** de AWS y emulación local desacoplada mediante **LocalStack** y **Docker**.

Este repositorio evoluciona la arquitectura del **Proyecto Tritón** incorporando patrones de **Infraestructura como Código (IaC)**, aprovisionamiento idempotente de recursos de cómputo/almacenamiento y orquestación programática de topologías de red privada (VPCs, Subnets, Internet Gateways y Security Groups).

CONTEXTO DE ESTE REPOSITORIO NUEVO: * **Proyecto en Solitario:** Este desarrollo fue realizado de manera **individual**, enfocándose en la automatización e infraestructura en la nube con Boto3 y LocalStack.
* **Proyecto Original:** La versión original del sistema de telemetría multicloud (desarrollada en el marco del Proyecto Tritón) también se encuentra disponible para consultar en mis repositorios de GitHub: https://github.com/FernandaPuca1811/triton_monitor.git
